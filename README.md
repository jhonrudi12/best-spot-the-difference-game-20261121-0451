**Twin Lanterns** — a spot-the-difference game that runs offline in a desktop browser from static files. Two near-identical hand-drawn pictures hang side by side; find every difference before the lanterns burn down.

Three original scenes, all drawn in code: **Harbour at Dusk**, **The Lantern Market**, and the **Moonlit Garden** — 9 differences each, with three difficulty levels (5, 7 or 9 differences per scene, 3:00 / 2:30 / 2:00 on the clock). Found differences get a green ring on both pictures; a live counter shows how many remain. Wrong clicks cost 5 seconds, hints cost 50 points, combos multiply your score, and every sound is synthesized live with WebAudio — no audio files, no network requests. Plays with mouse, keyboard, or both (arrow keys move the reticle, Space clicks, H hints, M mutes, R restarts).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play. Or open `game/index.html` from any static server.
